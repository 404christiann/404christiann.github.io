# Founderfolio preview assets

The twelve monochrome brand SVGs were extracted from the rendered Stack section of https://founderfolio.framer.website/ on October 10, 2026, at Christian's request. They are kept in their original order. Brand marks belong to their respective owners; they are used to identify technologies in a local design study. The retained stack is provisional and does not add verified experience claims.

github-2026.json is a public contribution-data snapshot for 404christiann retrieved October 10, 2026 from https://github-contributions-api.jogruber.de/v4/404christiann?y=2026. The HTML calendar is generated from this snapshot, not synthetic activity. The displayed total is 507. Dates outside 2026 are omitted. This static preview labels the snapshot date; it is not a live-updating GitHub integration.

The page uses Christian's existing portfolio content and secure project links. Founderfolio's copy, personal identity, tracking scripts, template promotion controls, and code are not included. Its visual layout is recreated as a reference study alongside a Pocket Studio hybrid.
